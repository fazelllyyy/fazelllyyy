I believe good software is not only about making things work.

It should be understandable, maintainable, and intentional. I prefer simple systems over unnecessary complexity, abstractions that earn their place, and interfaces that communicate clearly.

I learn by building, experimenting, and refining. My tools and areas of focus evolve with the problems I work on, but the way I approach software remains consistent: understand the problem, build with intent, and pay attention to the details.
