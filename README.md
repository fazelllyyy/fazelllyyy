# Zulfazli

**Software Engineer · Full-stack Developer · Builder**

I’m Zulfazli, a software engineer and independent builder from Indonesia.

I design and build software across different layers of the stack, from interfaces and applications to systems, tooling, and infrastructure. I enjoy turning ideas into software that is useful, well-structured, and pleasant to work with.

My interests span **software engineering, product development, developer tooling, user experience, and emerging technologies**. I value understanding the problem before choosing the technology, and I prefer simple solutions that remain maintainable as they grow.

### Approach

I care about software beyond whether it works.

Good software should have clear intent, thoughtful interfaces, sensible abstractions, and a strong foundation underneath. I pay attention to the details that often sit between engineering and design: how a system is structured, how an API feels to use, how an interface communicates, and how small decisions affect the overall experience.

I learn by building, experimenting, and refining.

### Currently

Exploring new ideas, building software, and continuously improving how I approach engineering and product development.

My work and interests evolve over time, so this profile intentionally stays focused on **what I do and how I think**, rather than a fixed list of technologies or projects.
